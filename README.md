# innovation_radar

Open `index.html` from the repository root in a browser to view the generic innovation radar. Keep `index.html`, `styles.css`, and `script.js` together in that same root folder, because the page loads the stylesheet and script through relative paths. Direct `file://` access was verified with Chromium for this repository, so no local web server is required for the current implementation. The demo page content is intentionally presented in English to match the repository documentation.
